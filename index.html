Lumen AI Studio

Generative tools for Illustrator

Palette Muse Offline

Pick a reference image. Lumen extracts its dominant colors with k-means and remaps the fills of your selected artwork onto that palette, darkest to lightest.

Drop an image here, or click to browse…

Select vector artwork (paths, groups, compound paths) on the artboard, then apply. Text fills included.

Pattern Dream Image API

Describe a tileable surface. Lumen renders it with your configured image model and places it on the Lumen AI layer as an embedded raster you can recolor or pattern-swatch.

Artboard Critique Vision API

Lumen exports the current artboard as a PNG and asks your vision model to critique composition, hierarchy, contrast and typography. Nothing leaves the machine except that PNG, sent to your configured endpoint.


      

    


    
    

      

        
Copywriter Text API

        
Generate headline/subcopy options from a brief, then write one straight into the selected text frame on the artboard — or create a new frame if nothing is selected.


        
        

          
          
        

        
        

      

    


    
    

      

        
Vector Muse Text API

        
Describe a simple flat graphic — icon, badge, spot illustration. Lumen asks the model for raw SVG, validates it, and places it on the artboard as scalable vector.

How keys are stored

        
Keys are written to lumen-ai-studio/config.json inside the CEP per-user data folder — never into the extension source, never into the .zxp. Delete them any time with Clear keys. Nothing is transmitted except to the Base URL you set.

        
Illustrator → Window → Extensions → Lumen AI Studio opens this panel.
